# TamiratGol

نسخه `0.5.0` یک MVP برای پایش هزینه نگهداری، گردش قطعات، تجهیزات و کیفیت داده است.

## قابلیت‌های نسخه 0.5.0

- داشبورد فارسی و راست‌به‌چپ با فیلتر سال و سایت
- روند ماهانه مبلغ خالص و مقایسه دو سایت
- مراکز هزینه با بیشترین حجم گردش مالی
- تحلیل نوع دستورکار و وضعیت کیفیت داده
- جست‌وجوی تجهیزات و قطعات پرتکرار یا پرهزینه
- شبیه‌ساز ۱۰ نقش و محدوده دسترسی
- ورود نرخ دلار هر سال و محاسبه معادل ارزی
- نگهداری نرخ‌های MVP در `localStorage` مرورگر
- ساختار آماده برای استقرار در Vercel

داده خام اکسل و توضیحات ردیفی در مخزن قرار نگرفته‌اند. فایل `src/data.json` فقط داده‌های تجمیعی لازم برای داشبورد را نگهداری می‌کند.

## اجرای محلی

```bash
npm ci
npm run dev
```

سپس آدرس نمایش‌داده‌شده توسط Vite را در مرورگر باز کنید.

## بررسی و ساخت

```bash
npm test
npm run build
```

خروجی تولیدشده در پوشه `dist` قرار می‌گیرد.

## استقرار در Vercel

1. مخزن را در Vercel وارد کنید.
2. تنظیمات پروژه از `vercel.json` خوانده می‌شود.
3. دستور نصب `npm ci` و دستور ساخت `npm run build -- --configLoader native` است.
4. پوشه خروجی `dist` است.

در این نسخه احراز هویت، پایگاه داده و فرایند واقعی تأیید نرخ ارز هنوز پیاده نشده‌اند. نقش‌ها و نرخ‌ها برای بررسی تجربه کاربری شبیه‌سازی شده‌اند.

## مسیر نسخه‌های بعدی

- اتصال احراز هویت سازمانی و اعمال Row-Level Security
- ذخیره و نسخه‌بندی نرخ ارز در پایگاه داده
- ورود کنترل‌شده فایل اکسل و گزارش خطاهای بارگذاری
- گردش تأیید نرخ ارز توسط کارشناس و مدیر مالی
- API و پایگاه داده برای داده‌های ردیفی و تاریخچه تغییرات
